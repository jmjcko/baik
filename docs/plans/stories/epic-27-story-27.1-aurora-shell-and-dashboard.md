## Acceptance Criteria

1. The Aurora tokens are in `globals.css` for both themes; no `backdrop-blur` in the source; dialogs dim with the scrim token.
2. `lucide-react` is the only icon source; icons are functional and hidden from screen readers next to a label; `AGENTS.md` states the new rule.
3. A header shows the mode, the garage bike switcher and the account and sync status on every page; the sidebar has the main navigation with icons and "My bikes".
4. The dashboard shows only real data (the five numbers of the active bike, the CAD drawing, the garage, the mobility tests); before the setup is done the cards say "not set up yet"; bAIkcare and bAIkshop are non-clickable tiles; no avatar, no search.
5. EN and CZ for every text; Light and Dark both work.
