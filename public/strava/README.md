# Strava brand assets

Strava requires its own, unmodified button for "Connect with Strava" and its "Powered by Strava" logo (https://developers.strava.com/guidelines/).
Download "Connect with Strava" (orange) from the brand guidelines and save it here as `btn_strava_connectwith_orange.svg`.
Until the file is here the card shows a plain button in the Strava colour with the same words.
